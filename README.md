# Superstore-dashboard
Recommended Structure and Order
1. Project Title 
 Superstore Sales Analytics Power BI Dashboard

2.Short Description 
 An interactive Power BI dashboard created using the Superstore dataset to analyze sales performance, profit trends, regional sales distribution, shipping modes, customer segments, and product categories. The dashboard helps businesses identify high-performing categories, profitable regions, and sales trends for better decision-making.

3.Tech Stack
 • Power BI  
• DAX (Data Analysis Expressions)  
• Power Query  
• Data Visualization  
• Microsoft Excel 

4.Data Source
 Dataset: Superstore Dataset

Contains:
• Order Date  
• Sales  
• Profit  
• Region  
• State  
• Category & Sub-Category  
• Segment  
• Ship Mode

5.Features 
 • Interactive Sales Dashboard  
• Region-wise Sales & Profit Analysis  
• Sales Trend Analysis by Order Date  
• Category and Sub-Category Performance Tracking  
• Customer Segment Distribution  
• Shipping Mode Analysis  
• KPI Cards for Total Sales and Profit  
• Dynamic Filtering using Region Slicer  
• Clean and Modern UI Design

6.Key Insights
 • Technology category generated the highest sales.  
• West region showed strong overall performance.  
• Consumer segment contributed major sales share.  
• Certain sub-categories performed significantly better than others.
